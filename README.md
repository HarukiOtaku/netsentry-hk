# NetSentry HK

每日科技、資安與 AI 摘要，**每條資訊都附上原始來源連結**，讓讀者用約 5 分鐘掌握當日重點，再自行點入原文深入了解。

- 🌐 網站：<https://netsentry-hk.vercel.app>
- 📮 RSS：<https://netsentry-hk.vercel.app/feed.xml>　·　JSON Feed：<https://netsentry-hk.vercel.app/feed.json>
- 👤 維護者 GitHub：<https://github.com/HarukiOtaku>

## 這個網站是甚麼

每天一篇摘要，分為以下模塊（讀者可以自行勾選想看的模塊）：

| 模塊 | 內容 |
| --- | --- |
| 📌 今日總結 | 當日最重要的事與主線，放在最頂 |
| ⚡ TL;DR | 三條最重要的一句話 |
| 產品與發布會 | 科技產品、AI 模型發布與大型發布會 |
| AI 模型與開源趨勢 | Hugging Face 等社群最受注目的模型 |
| GitHub 值得關注 | 與資安、AI 相關的開源項目 |
| 全球重點新聞 | 漏洞、勒索軟件、資料外洩、執法、政策 |
| 香港本地 | 本地資安警示、政策與業界動態 |
| 活動與展會 | 香港及亞洲（深圳／大灣區／日台星韓）線下活動、研討會與展覽 |
| 其他要點 | 其他值得留意的資訊 |

## 使用方式

- 頂部可勾選想看的模塊；未勾選的模塊不會顯示，選擇會記在瀏覽器。
- 可用網址參數分享指定組合，例如：`/?show=ai,github`。
- 「存檔」頁可翻查過去每一日；每篇都有固定永久連結。
- 支援深色／淺色模式（右上角切換）。

## 定位與聲明

- 本站**不取代傳統新聞媒體**，只是一個「每日總結層」；所有內容均附原始來源連結。
- 內容由 AI 自動彙整，**可能有錯漏或過時**，請以原始來源為準。
- 本站**不設追蹤、不設 cookie、不收集個人資料**，亦無廣告。
