# 關於本站

**NetSentry HK** 每日整理科技、資安、AI 與香港本地 IT 新聞，把一日之內最值得留意的資訊壓縮成一篇約 5 分鐘可以讀完的摘要。

## 本站嘅定位（重要）

- 本站**唔取代傳統新聞媒體**，而係一個「每日總結層」：幫你在短時間內掌握重點。
- **每一條資訊都附上原始來源連結**，你可以自行點入原文深入了解。
- 內容由 AI 自動搜集與整理，**可能有錯漏或過時**；所有細節請以原始來源為準。

## 點樣用本站

- 頂部有「**模塊勾選列**」：剔選你想看的模塊（TL;DR / 產品與發布會 / AI 模型與開源趨勢 / GitHub / 全球重點新聞 / 香港本地 / 活動與展會 / 其他 / 昨日跟進），未剔選的模塊不會顯示。
- 你的選擇會**記在瀏覽器**，下次開啟自動沿用；亦可以用網址參數分享特定組合，例如：`?show=ai,github`。
- 「**存檔**」可以翻查過去每一日的摘要，每篇都有固定永久連結。
- 右上角可以切換**深色／淺色模式**。

## 資料來源類別

- 官方公告（公司／機構自己發佈的部落格、公告、保安通告）
- 一手媒體報道
- 社群討論（例如開發者社群、開源項目頁面）

所有引用都會標明來源連結；若某項未能查證，會明確標示。

## 訂閱

不想每次都手動開啟網站的話，可以用訂閱工具自動接收每日更新：

- **RSS**：<https://netsentry-hk.vercel.app/feed.xml>（適用於 Feedly、Inoreader、NetNewsWire、Thunderbird 等）
- **JSON Feed**：<https://netsentry-hk.vercel.app/feed.json>（適用於支援 JSON Feed 的程式）
