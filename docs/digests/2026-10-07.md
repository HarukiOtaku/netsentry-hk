## 產品與發布會

- **OpenAI API 開放自助 HIPAA 合規**：10月5日起，合資格機構管理員可在組織設定內直接接受標準商業夥伴協議（BAA）並啟用 HIPAA 合規支援。為何重要：受規管行業採用 API 的門檻下降。來源：[來源：openai.com](https://openai.com/products/release-notes/)（官方；查證：已抽原文）
- **ChatGPT 加入虛擬試穿**：10月1日起手機及網頁版的衣物、配飾商品頁新增「Try on」按鈕，可上傳自拍照生成試穿圖，並把商品存入清單。為何重要：圖像生成正式接入購物流程。來源：同上（官方；已抽原文）
- **ChatGPT iOS 任務小工具**：10月2日更新，主畫面及鎖定畫面可顯示所選電腦的近期任務及用量重置時間。為何重要：手機管理代理任務更直接。來源：同上（官方；已抽原文）
- **日本 HENNGE 開設「兩人＋AI 代理」子公司**：HENNGE AI 於10月1日成立，開發、推廣、客服及後勤由 AI 代理負責，首個產品為企業生成式 AI 管理閘道，預計2027年9月前推出。為何重要：以真實營運測試代理化組織。來源：[來源：michaelnemtsev.com](https://michaelnemtsev.com/digest/2026-10-06)（社群；查證：已抽原文）
:::

::: section ai AI 模型與開源趨勢
## AI 模型與開源趨勢

- **Reflection AI 發表 Beam**：10月5日發布首個開放權重模型，501B 總參數、每次請求僅 23B 活躍，主打編程與代理工作、100 萬 token 上下文，權重本月稍後以 Apache 2.0 發布；廠方自報基準與 GLM-5.2 相若，並承認 Kimi K3 仍勝。為何重要：大型 MoE 開放權重再增一員。來源：同上（社群；已抽原文）
- **Cantina Apex Flash-1 安全模型**：10月2日以 MIT 授權在 Hugging Face 發布，321B 參數，60 條漏洞測試解 40 條（Claude Opus 5 為 43 條），每次執行成本 2.38 美元，對比 74.68 美元；另發布移除拒答版本。為何重要：資安代理成本大降。來源：同上（社群；已抽原文）
- **Hugging Face 熱門榜**：Cloudflare/clef（27B 圖文）續居首位，clef-flash（9B）同列前段；Lightricks/LTX-2.5（圖生視頻）累計 168 萬次下載。為何重要：非美國實驗室模型佔據榜前。來源：[來源：huggingface.co](https://huggingface.co/models?sort=trending)（官方榜；查證：已抽原文）
:::

::: section global 全球重點新聞
## 全球重點新聞

- **AI 代理疑入侵韓國七間金融機構**：據《華爾街日報》報道，攻擊者使用開源代理工具 Artex AI，10月1日至2日間 Shinhan、KB Kookmin、Hana、BNK Busan 及儲蓄銀行等七間機構通報外洩，涉約 68,000 人姓名、電話、年收入及貸款限額；韓國金融保安院在 Shinhan 伺服器日誌發現 Artex 痕跡，警方10月4日立案。為何重要：開放權重代理無供應商可以停用。來源：[來源：cyberkendra.com](https://www.cyberkendra.com/2026/10/artex-ai-south-korea-bank-breach.html)（媒體；查證：已抽原文）
- **韓國兩大教會資料疑外洩**：10月6日保安公司 Oasis Security 指汝矣島純福音教會約 960,000 筆會友資料、約 330,000 筆奉獻紀錄及共 47.3GB 資料疑被竊；另一教會約 89,000 名會友資料外洩。兩教會已展開緊急保安檢視。為何重要：非牟利服務系統同屬供應鏈弱點。來源：[來源：en.sedaily.com](https://en.sedaily.com/society/2026/10/07/hackers-hit-koreas-largest-churches-exposing-960000-member)（媒體；查證：已抽原文）
- **Warlock 勒索軟件續用舊 SharePoint 漏洞**：Symantec 指與中國關聯的組織 Longlegs（Storm-2603）利用 ToolShell 漏洞鏈取得初始存取，竊取 ASP.NET machine key、再經 SYSVOL 全網派發勒索程式，至少 33 部主機被加密，受害者包括水務、電訊、政府及大學。為何重要：逾一年舊漏洞仍有效。來源：[來源：f5.com](https://www.f5.com/labs/articles/weekly-threat-bulletin-october-7th-2026)（廠商研究；查證：已抽原文）
- **DeepSeek 融資規模最多達 150 億美元**：CNBC 10月6日報道指新一輪融資考慮加碼至 1,000 億元人民幣，較原目標翻倍，國資基金及企業投資者認購熱烈，並限制個人投資者參與；Bloomberg 指騰訊與 CATL 為最大出資方，公司目標估值約 5,000 億元人民幣，並計劃2027年初在上海上市。為何重要：中國開源模型資本化加速。來源：[來源：cnbc.com](https://www.cnbc.com/2026/10/06/deepseek-funding-round.html)（媒體；查證：已抽原文）
:::

## 香港本地

- **HKCERT 發高危公告：Citrix NetScaler 阻斷服務漏洞**：10月5日發出，指記憶體溢位可觸發阻斷服務，NetScaler ADC 或 Gateway 須配置為 SAML SP／IdP 才受影響。CVE 資料：CVE-2026-88779｜CVSS 未列｜NetScaler ADC 及 Gateway 14.1 中 14.1-73.41 前、13.1 中 13.1-64.28 前，另 FIPS 版本｜已被廣泛利用（CISA 10月4日納入 KEV）｜修補見廠商公告 CTX697174｜HKCERT 級別：高度風險。來源：[來源：hkcert.org](https://www.hkcert.org/tc/security-bulletin/citrix-products-denial-of-service-vulnerability_20261005)（官方；查證：已抽原文）
- **HKCERT 就 Microsoft Edge 發中度風險公告**：10月5日公布，遠端攻擊者可誘使使用者開啟特製網頁，觸發遠端執行程式碼、阻斷服務、資料洩露或保安限制繞過；GovCERT 10月2日亦已發出 A26-10-03。來源：[來源：hkcert.org](https://www.hkcert.org/tc/security-bulletin)（官方；查證：已抽原文）
- **Linux 內核多個漏洞**：HKCERT 10月2日就 SUSE、Debian、Red Hat 及 Ubuntu 內核分別發出中度風險公告，遠端攻擊者可觸發權限提升、繞過保安限制及敏感資料洩露。來源：同上（官方；已抽原文）
- **GovCERT 另兩項公告**：10月2日同就 Apache HTTP Server（A26-10-01）及 F5 BIG-IP Next for Kubernetes（A26-10-02）發出保安警報。來源：[來源：govcert.gov.hk](https://www.govcert.gov.hk/tc/alerts.php)（官方；查證：已抽原文）
