## 產品與發布會

- **Claude Code 新增「Mods」擴充層**：2026-10-01 隨 v2.1.287 推出，Mods 屬 TypeScript 事件函數，透過 Function Hooks 插入代理執行流程，可攔截及改寫工具呼叫、替換 React UI、跨鉤子共享狀態；官方內建 /diff、sec-default、telemetry 及測試框架。Mods 以完整使用者權限執行，可讀寫任何檔案、看到環境變數與 API key，且無審核、無簽章、無沙盒，只有 claude plugin validate 與 --safe-mode 作輔助。為何重要：擴充層權限等同使用者，安裝前必須自審源碼。來源：[來源：dev.to](https://dev.to/max_quimby/claude-code-mods-just-turned-agents-into-a-platform-5gc0) （類型：社群；查證：已抽原文）
