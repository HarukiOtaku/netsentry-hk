- **Cisco Secure Email Gateway 零日已被實戰利用**：CVE-2026-76461｜CVSS 9.8｜Cisco AsyncOS for Secure Email Gateway（15.5 及更早、16.0、16.5）｜已被利用：是｜修補：15.5.5-014／16.0.4-302／16.5.0-780｜HKCERT 級別：未能查證。未認證攻擊者只需送出一封含惡意 SQL 的電郵即可取得 root，廠方指攻擊者可能清除痕跡，須查防火牆及網絡日誌；無 workaround。來源：[來源：paubox.com](https://www.paubox.com/blog/cisco-secure-email-gateway-zero-day-exploited-to-gain-root-access)（類型：媒體；查證：已抽原文）
