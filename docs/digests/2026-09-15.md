::: section ai AI 模型與開源趨勢
## AI 模型與開源趨勢

- **Qwen/Qwen3.8-Flash-Next**：阿里首個行「Qwen4 架構」嘅開源權重實驗預覽，型號 tag 直接寫 `qwen4_exp`。三大新嘢係 Hybrid Attention（Gated DeltaNet + Qwen Sparse Attention，以 micro-block 為單位稀疏，大幅降長 context 延遲）、Gated Residual、N-gram Embedding（比 MoE 更易 offload，適合記憶體受限加速器）。官方講明正式版 Qwen3.8-Flash 預設 1M context 加內建工具。[來源：huggingface.co](https://huggingface.co/Qwen/Qwen3.8-Flash-Next)
- **zai-org/GLM-5.3-Flash**：320B 總參數／18B 活躍，GLM-5 系列首個原生多模態；用混合稀疏＋線性注意力、mHC（Manifold-Constrained Hyper-Connections）同 30T token 多模態預訓練語料。官方稱「十分一價錢」之下贏 GLM-5.2，coding／agentic 逼近 Claude Opus 4.8。[來源：huggingface.co](https://huggingface.co/zai-org/GLM-5.3-Flash)
- **開源生態觀察**：HF 趨勢榜前段仍然係 Qwen3.8 家族同 GLM-5.3 家族（Qwen3.8-27B 累計下載逾 5.7M），而量化／微調版嘅下載量往往反超原版 — unsloth 版 Qwen3.8-Flash-Next-GGUF 已錄 70 萬級下載，社群亦出咗 «Uncensored» 微調。⚠️ 誠實備註：本次 HF 趨勢頁只成功抓到統計數字，模型名稱由榜單快照對應，下載／like 數字可能有一至兩日延遲，未能逐個即時覆核。[來源：huggingface.co](https://huggingface.co/models?sort=trending&trending=true)
:::

::: section github GitHub 值得關注
## GitHub 值得關注

- **reconurge/flowsint**（TypeScript，8,275★／1,024 fork，單日 +279★，今日 trending）：畀資安分析師同行為調查人員用嘅視覺化「圖譜式」調查平台，把域名、帳號、基礎設施關係畫成 graph 追查。值得留意：以往做關聯分析要自己砌一堆工具，呢個係少見一次過包好嘅開源版本。[來源：github.com](https://github.com/reconurge/flowsint)
- **zhaoxuya520/reverse-skill**（15,620★，本週 +4,415★）：逆向工程／授權滲透測試用嘅「技能路由包」— AI 自動路由攻擊方法論、按需自舉工具鏈、自我進化經驗庫，支援 Claude Code／Kiro／Cursor／Cline。值得留意：同早前嘅 Claude-Red 一樣，AI agent 正被包裝成攻擊技能分發，紅隊入門門檻持續下降。[來源：github.com](https://github.com/zhaoxuya520/reverse-skill)
- **volcengine/OpenViking**（Python，30,725★，本週 +1,659★）：自我進化嘅「Agent 上下文資料庫」，統一 agent memory、Knowledge RAG 同 Skills。⚠️ 值得留意：該項目近日熱度明顯上升，採用者應同時留意版本更新與 skills 供應鏈風險。[來源：github.com](https://github.com/volcengine/OpenViking)
