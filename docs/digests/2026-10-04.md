- **Windows 11 File History 修復出爐**：KB5124010（24H2／25H2）及 KB5124006（26H1）可選預覽更新已修好 9 月更新引致的備份失效，未安裝者將於 2026-10-13 收到。為何重要：備份無聲失效等同無備份。來源：[來源：ghacks.net](https://ghacks.net/2026/09/25/microsoft-fixes-file-history-backup-failures-caused-by-september-windows-updates) （類型：媒體；查證：已抽原文）

## GitHub 值得關注

- **usestrix/strix**：開源 AI 滲透測試代理，60,221 星、6,584 fork、Apache-2.0，支援多代理協作、以真實 PoC 驗證漏洞，並可於 GitHub Actions 按 PR 攔截不安全程式碼。用途：自動化可驗證滲透測試。為何值得留意：以「無 PoC 不成立」壓低假警報。來源：[來源：github.com](https://github.com/usestrix/strix) （類型：社群；查證：已抽原文）

- **AIPentest/CyberStrikeAI**：以「意圖→受治理執行→證據成為記憶」為設計的 AI 原生資安執行系統。用途：治理化的代理式資安操作。為何值得留意：業界開始為代理加上執行約束。來源：同上
