::: section global 全球重點新聞
## 全球重點新聞

- **Zyxel GS1900 漏洞遭利用並列入 KEV**：CVE-2026-7273｜CVSS 8.8｜GS1900 全系列 2.90(AAHx.1)C0 及更早｜已被利用（09-21 納入 KEV）｜修補 2.90(AAHx.2)C0｜HKCERT：未見專屬公告。堆疊緩衝區溢位令未認證者可經特製 HTTP 請求執行 OS 指令；GreyNoise 指同一攻擊者已入侵 996 部交換器、涉 48 國及逾 18,500 筆後端紀錄。為何重要：邊緣設備仍是資料竊取入口。來源：CISA、BleepingComputer、GreyNoise（多來源；已抽原文）
- **Check Point 管理伺服器 pre-auth 0day**：CVE-2026-93616 令未登入者可在伺服器執行腳本，09-22 已發修補，公司稱 07-23 已有針對性攻擊；另有 Spark 防火牆 VPN 漏洞 CVE-2026-85102 自 09-12 起遭探測。為何重要：安全設備自身成突破口。來源：[來源：thehackernews.com](https://thehackernews.com/2026/09/check-point-warns-of-management-server.html)（媒體）
- **Arista VeloCloud 編排器 CVSS 10.0 漏洞已遭利用**：CVE-2026-93952，未登入遠端攻擊者可影響 VCO 主機，僅以憑證認證 Edge 的部署受影響；5.2.3.16、6.4.2.8 已修，6.1 與 7.0 未有修補。為何重要：SD-WAN 控制平面被拿下後果嚴重。來源：[來源：thehackernews.com](https://thehackernews.com/2026/09/new-cvss-100-velocloud-orchestrator.html)（媒體）
- **WordPress 修補重大漏洞**：CVE-2026-87902（CVSS 9.2），09-22 在 7.1.2 修好，4.7.0 至 7.1.1 全受影響，未認證即可利用，部分伺服器可進一步執行任意程式。為何重要：上週才更新過的網站仍要再更新。來源：[來源：thehackernews.com](https://thehackernews.com/2026/09/wordpress-issues-patch-for-critical.html)（媒體）
- **ShinyHunters 聲稱以 PeopleSoft 0day 入侵 FBI**：宣稱竊取 2 至 3TB 資料，涉現職及前員工、申請人資料，並橫向移動至 AWS GovCloud；截圖顯示 FBI 招聘網站被篡改。指控未經獨立核實。為何重要：未修補 0day 仍是最大風險。來源：[來源：bleepingcomputer.com](https://www.bleepingcomputer.com/news/security/shinyhunters-claims-fbi-hack-data-theft-in-peoplesoft-zero-day-breach/)（媒體）
- **新惡意程式 ClosedQuorum 用 LLM 決策**：以 Gemini、DeepSeek、Qwen 及 Mistral 模型自主決定後滲透階段行動。為何重要：攻擊自動化進入模型驅動階段。來源：[來源：bleepingcomputer.com](https://www.bleepingcomputer.com/news/security/new-closedquorum-windows-malware-uses-ai-for-attack-decisions/)（媒體）
:::
